## 🖼️ Spécifications techniques des assets

### Images PNG

**Résolution :** 512x512 pixels
**Format :** PNG avec canal alpha (transparence)
**Optimisation :** Compression via TinyPNG ou similaire (< 100 KB par image)
**Nommage :** `snake_case.png`

### Animations

**Format :** Lottie JSON (recommandé) ou PNG sprite sheets
**Dimensions :** 512x512 pixels
**FPS :** 30 fps
**Durée :** 2-3 secondes en boucle

### Positionnement des couches

L'ordre de superposition sur l'avatar :
1. **Base :** Photo de l'enfant (person.X) ou avatar par défaut
2. **Layer 1 :** Vêtements (clothes)
3. **Layer 2 :** Accessoires (accessory)
4. **Layer 3 :** Animaux de compagnie (pet) - coin inférieur droit
5. **Layer 4 :** Animations (animation) - effet d'overlay

### CSS z-index recommandé
```css
.avatar-base { z-index: 1; }
.avatar-clothes { z-index: 2; }
.avatar-accessory { z-index: 3; }
.avatar-pet { z-index: 4; }
.avatar-animation { z-index: 5; }
```

## 📝 Notes pour les développeurs

### Backend (Phase 7)

Le fichier `cosmetics.json` devra contenir tous ces items au format :

```json
{
  "id": "clothes_shirt_pirate",
  "name": "T-shirt Pirate",
  "description": "Un t-shirt à rayures rouges et blanches, parfait pour les aventuriers !",
  "category": "clothes",
  "subcategory": "shirt",
  "rarity": "common",
  "cost_coins": 15,
  "preview_image": "assets/avatars/clothes/shirts/tshirt_pirate.png",
  "unlock_requirements": null,
  "active": true
}
```

### Frontend (Phase 8)

Le `cosmetic-shop.ts` devra :
- Charger tous les items depuis le backend
- Filtrer par catégorie et rareté
- Vérifier les prérequis de déverrouillage
